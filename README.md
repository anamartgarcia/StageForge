# StageForge

StageForge enables event-driven, distributed applications with auto-scaling and self-healing capabilities, leveraging a scalable orchestrator manager.

With StageForge, you get a lightweight tool that stays out of your way.

**What you get**

- StageForge enables event-driven, distributed applications
- with auto-scaling and self-healing capabilities,
- leveraging a scalable orchestrator manager

## Key Features

- StageForge enables event-driven, distributed applications

- leveraging a scalable orchestrator manager

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/StageForge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

StageForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
